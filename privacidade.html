O REINO

Política de Privacidade

Aplicativo O Reino - Envio de vídeos · atualizada em 30 de outubro de 2026

O que é este aplicativo

O Reino - Envio de vídeos é uma ferramenta de uso próprio da equipe do livro O Reino: Uma Nova Utopia Social. Ela serve para publicar e atualizar vídeos (título, descrição e miniatura) no canal oficial do livro no YouTube. Não é um serviço aberto ao público e não tem cadastro de usuários.

Quais dados o aplicativo acessa

Quando a pessoa responsável pelo canal autoriza o acesso pela conta Google, o aplicativo recebe permissão para:

  • enviar vídeos ao canal do livro e alterar título, descrição e miniatura dos vídeos do próprio canal;
  • ler a lista de vídeos e o nome do canal, para conferir que está na conta certa.

O aplicativo só acessa o canal do livro. Não lê e-mails, contatos, arquivos nem dados de outras pessoas.

Como os dados são guardados

A chave de acesso fornecida pelo Google fica gravada apenas no computador da pessoa responsável pelo canal. Ela não é enviada a terceiros, não é publicada e não é vendida. Nenhum dado de visitantes, espectadores ou clientes é coletado, armazenado ou compartilhado por este aplicativo.

Uso dos dados do Google

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, inclusive os requisitos de Uso Limitado. As informações são usadas somente para as funções descritas acima.

Como revogar o acesso

A autorização pode ser retirada a qualquer momento em myaccount.google.com/permissions, escolhendo O Reino - Envio de vídeos e removendo o acesso. Depois disso o aplicativo deixa de funcionar até que uma nova autorização seja dada.
